# Spike 1: `manifold-rust` (`v0.19.2`, Pure Rust Manifold Mesh Booleans)

Прототип для архитектурного решения **P1-T3** ([`docs/adr/0001-geometry-kernel.md`](../../docs/adr/0001-geometry-kernel.md)), сравнивающий на одинаковой геометрии:
- **Вариант A (`manifold-rust v0.19.2`)**: чистый Rust-порт ядра [Manifold v3.5.4](https://github.com/elalish/manifold) ([`manifold-rust` на crates.io](https://crates.io/crates/manifold-rust/0.19.2), лицензия `Apache-2.0`, `build = false`, без C++ и FFI), использующий точные целочисленные/рациональные предикаты (`dashu-int`, `dashu-ratio`, `clipper2-rust`) и нативную трассировку происхождения граней (`MeshGLP::face_id` и `run_original_id`).
- **Вариант D (`mcp-cad-core` BSP-CSG)**: текущая реализация булевых операций на BSP-деревьях в `crates/mcp-cad-core/src/csg.rs`.

## Тестовая геометрия (по ТЗ P1-T3)

1. **Цилиндр**: $R_{\text{out}} = 15\text{ мм}$, $h = 50\text{ мм}$ ($z \in [-25, +25]\text{ мм}$, `segments = 64`).
2. **Минус коаксиальное сквозное отверстие**: $\varnothing 20\text{ мм}$ ($R_{\text{in}} = 10\text{ мм}$).
3. **Плюс бокс-фланец**: $40 \times 40 \times 10\text{ мм}$ ($z \in [-20, -10]\text{ мм}$) со сквозным центральным отверстием $\varnothing 20\text{ мм}$.
   - Точный аналитический объём фланцевой втулки (гладкие окружности):
     $$V_{\text{exact}} = \pi (15^2 - 10^2)\cdot 50 + (40^2 - \pi \cdot 15^2)\cdot 10 = 16\,000 + 4\,000\pi \approx 28\,566.3706\text{ мм}^3$$
   - Точный аналитический объём для 64-угольной аппроксимации цилиндра и отверстия:
     $$V_{64\text{-gon}} = 28\,546.1940\text{ мм}^3$$
4. **Скругление 4 вертикальных рёбер фланца $R = 2\text{ мм}$**: вычитание угловых скругляющих призм (так как `manifold-rust` является сеточным булевым ядром без B-Rep rolling-ball скруглений произвольных 3D-рёбер).
   - Точный аналитический объём после скругления 4 вертикальных рёбер ($L = 10\text{ мм}$ каждое):
     $$V_{\text{filleted}} = V_{\text{exact}} - 4\cdot\left(1 - \frac{\pi}{4}\right)\cdot 2^2 \cdot 10 \approx 28\,532.0343\text{ мм}^3$$
5. **Проверка сохранения идентификатора грани торца (`face_id`)**:
   - До булевых операций треугольникам верхней крышки цилиндра ($z = +25\text{ мм}$) назначается `face_id = 101` (`cyl:cap_top`), стенке отверстия — `face_id = 203` (`hole:wall`), граням фланца — `301..306`.
   - После `union` + `difference` из `MeshGLP<f64, u32>` извлекаются треугольники с `face_id == 101` и сверяется их суммарная площадь с площадью кольцевого торца $\pi(15^2 - 10^2) \approx 392.6991\text{ мм}^2$ ($392.0686\text{ мм}^2$ для 64-угольника).
6. **Бонусный стресс-тест `T08_hex_nut_m10` (внутренняя резьба М10×1.5, задача `P3-T11`)**:
   - Вычитание винтового тела `create_helical_cutter_with_settings` (`metric_60`) из шестигранной заготовки гайки с отверстием.

## Команда запуска

Из корня репозитория:

```bash
cargo run --release --manifest-path spikes/manifold_rust/Cargo.toml
```
