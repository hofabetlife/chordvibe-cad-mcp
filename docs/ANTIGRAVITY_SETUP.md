# Интеграция с Google Antigravity и Antigravity 2.0

**MCP-CAD Engine** полностью совместим с платформой **Google Antigravity** и десктопным приложением **Antigravity 2.0**.

---

## 1. Автоматическая конфигурация (уже выполнена)

Сервер зарегистрирован в глобальном конфигурационном файле Antigravity:
`C:\Users\voley\.gemini\config\mcp_config.json`

```json
{
  "mcpServers": {
    "mcp-cad": {
      "command": "C:/Users/voley/Documents/3D_MCP/target/release/mcp-cad-server.exe",
      "args": ["--mode", "stdio"]
    }
  }
}
```

> **Примечание**: Если вы хотите, чтобы при каждом обращении ИИ на экране Windows также автоматически открывалось интерактивное 3D-окно, замените аргументы на:
> `"args": ["--mode", "stdio", "--gui"]`

---

## 2. Где и как отображается сервер в Antigravity 2.0

После перезапуска приложения или старта новой сессии:

1. **Левая боковая панель (Left-hand Sidebar)**:
   - Перейдите в раздел **Skills & Customizations** (или кликните на меню **Additional Options (...) > MCP Servers**).
   - В списке активных серверов появится **`mcp-cad`** со статусом подключения и списком всех 15 доступных инструментов.

2. **В строке ввода чата (Chat Canvas)**:
   - Наберите символ **`@`** — в выпадающем меню контекста появится раздел MCP с сервером `mcp-cad` и его инструментами (`@mcp-cad`, `@create_part`, `@run_fea_analysis` и др.).

3. **В системном контексте агента**:
   - Агент автоматически видит инструменты `mcp_cad_*` и использует их для выполнения инженерных задач без необходимости дополнительных настроек.

---

## 3. Проверка работы из диалога с Antigravity

Просто отправьте агенту запрос:
```text
@mcp-cad Спроектируй деталь из алюминия 6061-T6 (куб 100x100x100 мм), закрепи нижнюю грань и приложи силу 10000 Н сверху. Проведи расчет прочности и покажи тепловую карту напряжений.
```

Агент выполнит:
1. `create_part(name="test_cube", material="aluminum_6061_t6")`
2. `add_feature_primitive(...)`
3. `run_fea_analysis(...)`
4. `get_fea_heatmap_image(...)`
5. Предоставит вам расчет коэффициента запаса прочности ($FoS$) и снимок деформаций.
