## 1. Диагностика проблем

В ходе исследования задачи `P3-T12` (выявленной при подготовке `ADR-0001` в рамках `P1-T3`) были локализованы и устранены две корневые проблемы:

1. **Однокомпонентная формула топологического рода `genus` в `validate_mesh_options` (`crates/mcp-cad-core/src/diagnostics.rs`)**:
   - Ранее топологический род вычислялся до подсчёта числа связных компонент `connected_components` ($k$) по формуле для одной замкнутой оболочки:
     $$g = \frac{2 - \chi}{2}$$
   - При булевом объединении $k \ge 2$ непересекающихся тел (например, двух сфер или двух кубов с $\chi = 2 + 2 = 4$ и $k = 2$) формула возвращала $g = (2 - 4)/2 = -1.0$ вместо $0.0$, из-за чего `validate_mesh(&mesh, Some(0))` ошибочно завершался со статусом `"FAIL"` (`Euler genus mismatch: computed -1.0 (round -1), expected 0`).
   - В соответствии с обобщённой характеристикой Эйлера–Пуанкаре для $k$ ориентируемых замкнутых поверхностей:
     $$\chi = V - E + F = 2k - 2g \implies g = \frac{2k - \chi}{2}$$

2. **Топологическая замкнутость и качество сетки составной фланцевой втулки (`union + difference`) в `crates/mcp-cad-core/src/csg.rs`**:
   - При построении составной фланцевой втулки (`csg_union(&create_cylinder(15.0, 50.0, 64), &create_box(40.0, 40.0, 10.0))` с последующим вычитанием сквозного отверстия `csg_difference(&u, &create_cylinder(10.0, 52.0, 64))`):
     - В конфигурации с компланарным нижним торцом фланца ($z \in [-25, -15]$, заподлицо с $z_{\min} = -25$ цилиндра) при числе треугольников $> 2000$ функция `repair_manifold_triangles` ограничивала число проходов `max_passes = 2` и не удаляла одиночные вырожденные «лепестковые» треугольники (`is_dup_flap`), у которых одно направленное ребро дублирует уже замкнутое ребро (`c >= 2 && u >= 3`), а другое остаётся открытой границей (`u == 1`). Это оставляло `3` открытых граничных ребра и `1` не-манифольдное ребро (`chi = -1`).
     - В `refine_coplanar_sliver_fans_and_edges` цикл устранения узких треугольников (`< 5°`) завершался через `break` при первой же треугольной грани `seed_idx` на 90°-м ребре пересечения цилиндра и фланца, которую нельзя было перестроить локальным компланарным веером Штейнера, оставляя необработанными остальные компланарные sliver-треугольники на плоских торцах фланца (`1.42% > 1.00%` в `validate_mesh_strict`).
     - Кроме того, аналитический манифольдный быстрый путь сквозного соосного отверстия `try_cut_coaxial_through_bore` проверял только `f.role == "hole_wall"` (от `cut_hole`), игнорируя прямое булево вычитание соосного цилиндра `csg_difference(&u, &create_cylinder(...))` (`f.role == "side"` при `a.faces.len() > 3`).

## 2. Выполненные изменения

1. **Обобщённая формула Эйлера–Пуанкаре в `crates/mcp-cad-core/src/diagnostics.rs`**:
   - Вычисление `genus` перенесено после BFS-подсчёта `connected_components` и реализовано по формуле:
     ```rust
     let genus = if connected_components > 0 {
         (2.0 * (connected_components as f64) - (euler_characteristic as f64)) / 2.0
     } else {
         0.0
     };
     ```
   - Добавлен модульный тест `test_validate_mesh_disjoint_union_connected_components_genus`, проверяющий несвязные объединения двух ($k = 2, \chi = 4, g = 0$) и трёх ($k = 3, \chi = 6, g = 0$) кубов, а также куба и перфорированной пластины с отверстием ($k = 2, \chi = 2, g = 1$).

2. **Устранение открытых/не-манифольдных рёбер и игольчатых треугольников на фланцевой втулке (`crates/mcp-cad-core/src/csg.rs`)**:
   - В `repair_manifold_triangles` снято искусственное ограничение `max_passes = 2` для сеток $> 2000$ треугольников (`max_passes = 8`) и добавлена очистка дублирующих лепестковых треугольников (`is_dup_flap`: `(c >= 2 && u >= 3)` при наличии открытого граничного ребра `u == 1`) с последующим автоматическим запечатыванием 3-рёберного контура.
   - В `refine_coplanar_sliver_fans_and_edges` вместо досрочного выхода `if !modified { break; }` введён реестр `unrefinable_tris: HashSet<[u32; 3]>`, позволяющий пропускать нередуцируемые угловые треугольники на стыке граней и гарантированно обрабатывать все компланарные веера на плоских гранях фланца, а также добавлена предфильтрация `plane_verts` в плоскости текущей грани.
   - В `try_cut_coaxial_through_bore` добавлена поддержка соосного цилиндрического инструмента `b` (`f.role == "side" && b.faces.len() == 3`) при вычитании сквозного отверстия из составных соосных тел (`a.faces.len() > 3`).

3. **Новые замечания, занесённые в `TASKS.md`**:
   - В ходе проверки workspace обнаружено, что изолированный спайк `spikes/manifold_rust/src/main.rs:170` использует структурный литерал `TriangleMesh { vertices, indices }` без полей `face_ids` и `faces`, добавленных в `P2-T6`. Проблема зарегистрирована в бэклоге как задача **`P3-T18`**.
